One line for make.fun's "Till Firmware Do Us Part" bounty: a wedding vow spoken at a robot wedding. It keeps the shape of a real vow — through everything, until the end — and swaps the human milestones for the ones a machine would actually face: updates, crashes, low battery, powering down together. Funny on the surface, sincere underneath.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) writes the entry line to `out/entry.txt` locally, or to `/output/entry.txt` where the competition runs it. The line is one sentence under 200 characters.
